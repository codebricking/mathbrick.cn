## 概览

mathbrick（数砖）是一个面向考研数学（数一 / 数二 / 数三）考生的一站式学习方案。真题、考点、几何可视化讲解、组卷模考、AI 估分与批阅、公式手册、错题复习都在同一个站里打通，注册后免费使用。同门「码砖 codebrick」做 408，数砖做数学，一套工程班底、两个学科。

站内除了大家都有的**考纲章节轴**，还多做了一根**解题方法轴**——「破题诀」把全站的题按「该用哪一招」重排成 197 招，这是数砖与其他题库产品最大的不同。

## 主要功能

> 完整功能清单、逐一入口链接与分阶段用法见 **[功能地图](./功能地图.md)**。

**⚔️ 破题诀 —— 按「解题招法」重排的一根新轴**
- 不按考纲章节，按**这道题该用哪一招**组织题：**197 招 · 24 个板块**
- 每一招写清四件事：什么时候用它 / **容易错在哪** / 这招走不通改用哪招 / 近十年考过几回
- 「走不通时」是可点的按钮，161 条转招关系（73 条跨板块）——题册只告诉你「这题怎么做」，不告诉你「卡住了往哪走」
- **交错验收小测**：把本招的题混进别招的题里、不告诉你哪道是哪道，认出该用哪一招本身就是要验的东西；通过即得跳过权
- 每道题卡上都能反查「这类题该用哪一招」
- → **[单独一篇详细介绍](./破题诀.md)**

**真题与练习**
- 911 道历年真题（2009–2026，数一 / 数二 / 数三 全覆盖），逐题解析、按考点归档、按卷组织
- 真题档案区另收录 1987–2008 共 1273 道，全库合计 2184 道
- 十一种刷法各取所需：破题诀、难度阶梯练、按年练、章节练习、复习专题、难题榜、跨卷加练等
- 巩固题：9 本主流教辅习题集共 8653 道，补齐真题没覆盖到的题型；与真题共用同一套刷题壳
- 可按年份留题（把最近 3/5/10 年的卷留给全真模拟），也可切「只看解析」回看模式
- 收藏夹 / 笔记 / 草稿纸（内置公式编辑器，支持手写笔与数位板）/ 错题本

**组卷与模考**
- 一键按真题结构生成 150 分整卷，也可手动筛年份 / 题型 / 难度 / 考点 / 招法抽题
- 题源可选真题 / 巩固题 / 混合；另有「弱招猛攻」——卷子结构一格不动，每格优先挑你错得多、还没练过的招
- 限时作答 + 交卷估分，默认 180 分钟对齐真考
- 抽题非随机：未做优先 + 已做冷却，不会反复撞见同几道

**概念可视化**
- 交互式几何讲解图，覆盖极限、导数、积分、微分方程、多元微积分、级数、二次型等核心考点
- 从二维到三维（切平面、空间曲线切线法平面、鞍面判别等），做竞品普遍缺失的「理解型」图
- 约 84% 真题已挂讲解图：解析页内嵌「考点讲解图」，点开即看

**AI 辅助**
- AI 大题批阅：按官方采分点逐点评判、给出命中 / 缺失点与估分，覆盖 1992–2026 共 543 道大题、3122 个采分点
- 拍照批阅：手写解答拍一张传上来，视觉模型看着原图判分，不必誊成文字
- AI 答疑：可绑定题目上下文提问，答疑中内联生成讲解图

**公式手册**
- 27 章、521 条主要公式，做题不翻书
- 解析页内嵌「相关公式」折叠区，按考点自动反查命中

**记忆与复习**
- FSRS 间隔重复调度 + 考前记忆峰值
- 错题本（做错自动进、连对若干次自动出本，阈值可调，支持批量出本与打印）+ 今日待复习 + 今日错题（晚上复盘专用）
- 速记卡：结论与公式的主动回忆，同样按 FSRS 排复习
- 导入题目：站外题录进来一样刷、一样复习，仅自己可见

**学情与数据**
- 错题诊断：按「正确率 × 考频」定位最该补的考点，规则透明可核对
- 考点掌握图 / 章节自评 / 月度成绩单（只跟上个月的自己比，不做跨用户排名）
- 数据大盘 / 命题结构 / 考点透视 / 题号方阵 / 学习路径
