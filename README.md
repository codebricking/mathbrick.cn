## 概览

mathbrick（数砖）是一个面向考研数学（数一 / 数二 / 数三）考生的一站式学习方案。真题、考点、几何可视化讲解、AI 估分与批阅、公式手册、错题复习都在同一个站里打通，注册后免费使用。同门「码砖 codebrick」做 408，数砖做数学，一套工程班底、两个学科。

## 主要功能

**真题与练习**
- 905 道历年真题（2009–2026，数一 / 数二 / 数三 全覆盖），逐题解析、按考点归档、按卷组织
- 收藏夹 / 笔记 / 草稿纸（内置公式编辑器）/ 错题本
- 真题卷视图：按年份整卷浏览，一键进单题

**概念可视化**
- 交互式几何讲解图，覆盖极限、导数、积分、微分方程、多元微积分、级数、二次型等核心考点
- 从二维到三维（切平面、空间曲线切线法平面、鞍面判别等），做竞品普遍缺失的「理解型」图
- 约 77% 真题已挂讲解图：解析页内嵌「考点讲解图」，点开即看

**AI 辅助**
- AI 大题批阅：按官方采分点逐点评判、给出命中 / 缺失点与估分（覆盖 2009–2026 全部大题，含 1771 个采分点）
- 支持公式所见即所得输入，草稿纸本机自动保存

**公式手册**
- 27 章、519 条主要公式，做题不翻书
- 解析页内嵌「相关公式」折叠区，按考点自动反查命中

**记忆与复习**
- FSRS 间隔重复调度 + 考前记忆峰值
- 错题本 + 今日待复习
- 弱考点定位与针对性推题

**考研英语（新增）**
- 阅读真题（2016–2026）逐题解析、英语一 / 英语二整卷视图
- 词汇速测、写作与模考模块
